# Contributing — Best Brightness Smart POS

## Workflow

1. One feature per branch / focused commit  
2. Conventional commits: `feat(scope):`, `fix(scope):`, `chore:`, `docs:`  
3. Do not commit `.env` or secrets  

## Quality checklist

- [ ] TypeScript strict — no `any` without justification  
- [ ] Matches dark luxury design system  
- [ ] Keyboard accessible; visible focus  
- [ ] Loading + empty + error states  
- [ ] Motion intentional and subtle  
- [ ] Images via Storage URLs only  

## Docs to keep current

Update `PROJECT_SPEC.md` / `ARCHITECTURE.md` / `DESIGN_SYSTEM.md` when behavior or structure changes materially.
