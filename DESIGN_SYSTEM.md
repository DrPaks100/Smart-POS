# Design System — Best Brightness Smart POS

## Philosophy

Premium retail POS aligned with the login experience: white canvas, rich blended accents, soft depth, bold type.

## Color

| Token | Value |
| --- | --- |
| Canvas | `#f7f8fc` |
| Surface | `#ffffff` |
| Ink | `#0f172a` |
| Muted | `#64748b` |
| **Blend** | `#84cc16 → #0d9488 → #2563eb → #7c3aed` |

Use `.bb-blend-bg` for primary actions / active nav.  
Use `.bb-blend-text` for accents and totals.  
Use `.bb-ambient` for soft corner glow on app shells.

## Surfaces

Glass cards: white / frosted + soft blue-violet shadow.  
Radius: `1.25rem` cards, `0.875rem+` controls (bubbly, not sharp).

## Spacing

Tight retail density: `gap-3`, `p-4`, compact sidebar. No large empty voids.

## Typography

Manrope UI · Space Grotesk titles · **extrabold** brand / page titles.
